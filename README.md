# Crazy Cattle 3D Browser Game

Браузерна 3D гра на Three.js

## Як запустити

1. Склонуйте репозиторій
2. Запустіть локальний сервер (наприклад, використовуючи Python):
   ```bash
   python3 -m http.server
   ```
3. Відкрийте браузер і перейдіть за адресою: http://localhost:8000

## Керування

- WASD - рух
- Пробіл - стрибок
- Миша - огляд
- ЛКМ - стрільба
- R - перезарядка

## Структура проекту

```
/
├── index.html          # Головний HTML файл
├── main.js            # Основний JavaScript код
├── styles.css         # Стилі
└── models/            # 3D моделі
    ├── character/     # Модель персонажа
    └── environment/   # Моделі оточення
```
