# Crazy Cattle 3D (Browser Edition)

Це спрощена та оптимізована браузерна версія гри CrazyCattle3D.

## Як запустити гру
1. Відкрийте файл `index.html` у будь-якому сучасному браузері.
2. Керування: WASD — рух, Пробіл — стрибок, Миша — обертання.

Гра працює повністю локально, без потреби у сервері чи додаткових плагінах.
